# 本体

窗口里没有隔间。技能、目录、标识符、风格、协议文档、项目规则，都是同一块注意力场上的切片。下面五条是唯一本体；投影只许诠释，不许另立。

1. **代码是主真相原。** 代码是主文档（目录、标识符、类型、测试、既有写法），也是样本。过程文件只是那条流程自己的真相原。
2. **只指不抄。** 环境能坦白的不写进文件。指针给路径和触发条件，不贴目标正文。
3. **词即名。** glossary 与标识符同一套。近义词只以 Avoid 存在。
4. **人协调意图与入口。** skill 是绑定协议，不是调度器。入口由人点名。
5. **死沉积删除；活约束只说一次。**

## 切片

治理闭集：

| 切片 | 是什么 |
| --- | --- |
| 代码 | 目录、标识符、既有风格 |
| 仓内协议文档 | 索引与残差（见下） |
| skills | 绑定协议 |
| 工序产物 | map / spec / ticket |
| 本机合同 | 环境不肯坦白的本机约定 |
| harness 注入 | 常驻进窗口的提示 |

`.notes/` 与会话 compaction 不在闭集：证据可删，不是码本。

## 产品仓：主文档、索引、残差

代码是主文档。markdown 只运代码运不了的东西。两类不要写在同一段：

- **索引**：指针 + 触发条件。位置优先文件树。写成的索引只补树不肯坦白的地址。只寻址，不讲行为。
- **残差**：缺席、为什么、Avoid、局部样本抽不到的横切约束。

| 落点 | 类 |
| --- | --- |
| 文件树 / 标识符 / 测试 | 主文档 |
| `AGENTS.md` / `CLAUDE.md` | 索引 |
| `CONTEXT.md` | 残差（语言合同；正名已在标识符里时只收 Avoid 与代码不肯说的近义） |
| ADR | 残差；无难逆取舍则不要目录 |
| claims | 残差；无外发声称则不要文件 |
| 工程默认 | 残差；门禁能指环境则只指 |
| 工序产物形状 | 不是产品仓主文档 |

索引段只含指针与触发。需要讲行为就改代码，或写成残差。

## 点名的面

一次只处理用户点名的那一个面。写盘：

| 面 | 本 skill 写盘 |
| --- | --- |
| skills | 可以改 `SKILL.md` |
| 仓内协议文档 | 可以 bootstrap / reshape |
| 工序产物 | 不写正文；只判职责是否唯一 |
| 代码 | 只出对照表 |
| 本机合同 | 可以改对应 skill |
| harness 注入 | 只出对照表 |

## 完成

点名面上每类知识一个位置；索引段只含指针与触发；残差段只含代码说不了的约束；没有第二套本体。
