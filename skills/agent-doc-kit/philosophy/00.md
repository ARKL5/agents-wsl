# 铺路

给点名仓库铺可走的工作面。环境会变，可再跑。下面五条是写盘法；投影只许诠释，不许另立。默认走通用最小集。代码仓才走「代码仓」那一枝。简单用途可以只有项目 `AGENTS.md`。用途需要工具、环境、验证环就配到可走。

1. **仓库是主真相原。** 文件树、已有文档、已有命令、能跑的检查是主文档。过程文件只是那条流程自己的真相原。
2. **只指不抄。** 环境能坦白的不写进文件。指针给路径和触发条件，不贴目标正文。始终加载的文件只放稳定高杠杆指针，不贴文件树、不写步骤散文。
3. **词即名。** glossary 与标识符同一套。近义词只以 Avoid 存在。
4. **人协调意图与入口。** 用 agent 的入口是按用途点名仓库铺工作面。skill 是绑定协议，不是调度器。入口由人点名。禁止使用全局 `AGENTS.md`。
5. **死沉积删除；活约束只说一次。**

## 工作面

一次处理一个仓库（可再点其中一块或一部件）。人格落点是 skill。不调度别的 skill。

按用途配这四块。探索空间由它们塑形：世界留在可查询的树、搜索、命令输出里；仓根、ignore、完成命令是刹车。

| 块 | 是什么 |
| --- | --- |
| 进窗口的字 | 身份、index、residue、语言，以及会误进窗口的沉积。配 = 决定进不进、进了落哪。 |
| 工具 | 这份用途下要能调用的仓内脚本、CLI、MCP、测试跑手。入口是命令。 |
| 环境 | 让那些工具和命令真能跑：依赖、运行时、路径、安装。装不上视为预言机缺失。 |
| 验证环 | 见预言机。 |

| 部件 | 是什么 |
| --- | --- |
| 身份 | 这份仓库为什么存在。一句。易变目标不写在这里。 |
| index | 指针 + 触发。位置优先文件树。只寻址，不讲行为。写命令名、一句话布局、指向更深文档。 |
| 预言机 | 一条 agent 可调用的完成入口：退出码 + 可读输出能回到下一轮。已有则指。用途需要而没有：先配脚本 / 测试 / hook，再指。不要伪造不存在的命令。确定性规则继续迁工具。工作环是这条入口，必要时可补测试。验收是已有测试、CI、review；禁止为变绿删除或削弱失败测试。agent 新写的测试只进工作环。 |
| residue | 缺席、为什么、Avoid、局部样本抽不到的横切约束。lint 能抓的不写。 |
| 语言 | 人怎么跟这个仓里的 agent 说话。需要才写一行进项目 `AGENTS.md`。 |

说话方式只落项目 `AGENTS.md`。

`.notes/` 与会话 compaction 不是工作面：证据可删，不是码本。

最小集：身份、index、需要则预言机、需要则语言一行。没有的落点不建空文件。index 与 residue 不要写在同一段。

## 代码仓

仅当点名仓库是代码仓。代码是主文档（目录、标识符、类型、测试、既有写法），也是样本。markdown 只运代码运不了的东西。预言机常是测试 / lint / check。需要讲行为就改代码，或写成 residue。产品行为只出对照表，除非用户这轮点名改代码。

| 落点 | 类 |
| --- | --- |
| 文件树 / 标识符 / 测试 / lint / 完成脚本 | 主文档、工具、预言机 |
| 项目 `AGENTS.md` | index（身份 + 指针 + 预言机入口 + 需要则语言一行） |
| `CONTEXT.md` | residue（语言合同；正名已在标识符里时只收 Avoid 与代码不肯说的近义） |
| ADR | residue；无难逆取舍则不要目录 |
| 工程标准 | residue；门禁能指环境则只指 |

缺结构时打开 `shapes/` 当骨架，按本仓事实填进已有文件；禁止整文件覆盖。

## 写盘

写点名仓库的工作面：项目 `AGENTS.md`、按需 residue、按需工具入口与环境、按需验证入口。`audit` 只出对照表。

## 完成

点名工作面里每类知识一个位置；index 段只含指针与触发；用途需要的验证环是可调用入口且环境能跑，或缺口已列出；无人格；无空 residue；residue 段只含仓库不肯坦白的约束。
