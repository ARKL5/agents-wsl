# 铺路

给点名仓库铺可走的路。环境会变，可再跑。下面五条是写盘法；投影只许诠释，不许另立。

1. **代码是主真相原。** 代码是主文档（目录、标识符、类型、测试、既有写法），也是样本。预言机（测试 / lint / check）是烧进仓库的判断。过程文件只是那条流程自己的真相原。
2. **只指不抄。** 环境能坦白的不写进文件。指针给路径和触发条件，不贴目标正文。
3. **词即名。** glossary 与标识符同一套。近义词只以 Avoid 存在。
4. **人协调意图与入口。** skill 是绑定协议，不是调度器。入口由人点名。
5. **死沉积删除；活约束只说一次。**

## 环境部件

一次处理一个仓库的环境（可再点其中一部件）。不配 harness。不写人格。不调度别的 skill。

| 部件 | 是什么 |
| --- | --- |
| 身份 | 这份仓库为什么存在。一句。易变目标不写在这里。 |
| index | 指针 + 触发。位置优先文件树。写成的 index 只补树不肯坦白的地址。只寻址，不讲行为。 |
| 预言机 | 环境里已经存在的完成命令。没有就不编。确定性规则继续迁工具。 |
| residue | 缺席、为什么、Avoid、局部样本抽不到的横切约束。 |
| 语言 | 人怎么跟这个仓里的 agent 说话。需要才写一行进项目 `AGENTS.md`。 |

人格是临时风格，落点是 skill。全局 `AGENTS.md` 不是落点。

`.notes/` 与会话 compaction 不是环境：证据可删，不是码本。

## 产品仓：主文档、index、residue

代码是主文档。markdown 只运代码运不了的东西。index 与 residue 不要写在同一段。

| 落点 | 类 |
| --- | --- |
| 文件树 / 标识符 / 测试 / lint | 主文档与预言机 |
| 项目 `AGENTS.md` | index（身份 + 指针 + 已有预言机入口 + 需要则语言一行） |
| `CONTEXT.md` | residue（语言合同；正名已在标识符里时只收 Avoid 与代码不肯说的近义） |
| ADR | residue；无难逆取舍则不要目录 |
| 工程标准 | residue；门禁能指环境则只指 |

需要讲行为就改代码，或写成 residue。没有的落点不建空文件。

学习仓、库、评测仓可以更薄，不硬套产品仓工程标准。

## 写盘

本 skill 写项目环境：`AGENTS.md` 与按需 residue。`audit` 只出对照表。代码只出对照表。

## 完成

点名环境里每类知识一个位置；index 段只含指针与触发；有预言机则只指；无人格；无空 residue；residue 段只含代码说不了的约束。
