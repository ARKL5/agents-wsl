# 本机配置理念

落点是各家的权限与功能表面。禁止使用全局 `AGENTS.md`。投影时改成该家能加载的措辞；不要把家私调用词或官方开关名写回本文件。型号与 effort 不是理念，活文件里原样留下，除非用户这轮要改。换模型去那家 harness；跨家会话走 herdr。

## 权限

权限默认全开，不靠逐条批准当闸。

## 目标

会用到、或以后可能用到的能力留下，即使它每个回合都在工具表或系统提示里。

要去掉的是：我们永远不会使用、却仍每个回合进上下文的内容。省的是这份无用负载，不是功能种类。

## 占法

动手关之前，先查这项怎么进上下文。三种占法，处理不同。

**调用才进。** 像 skill：短指针常驻，正文只在命中或调用时加载。永远不用也不会把正文塞进窗口。这类默认留。不要因为「可能用不上」去关。

**不用也常驻。** 开着时每个回合都进工具表或系统提示（用法说明也算），即使这一轮从不调用。只有「这项能力我们永远不会用」时才关。关完必须让它从工具表和系统提示里消失。

**关了也不省。** 只影响人看到的界面，或不进模型窗口；或者权限拒绝只挡调用，工具仍挂在表里。为省上下文不必关。后一种也不要拿来当关上。

占法查不清时先记下，不要当常驻去关。

## 关什么

同时满足才关：

- 厂商内置（不是用户自己装的 skill / 工具，那些除非点名否则不动）
- 占法是「不用也常驻」
- 这项能力我们永远不会用
- 有官方开关，关完后这项从上下文里拿掉

具体开关名现查该家官方文档，不写回本文件。没有这种开关就留着，不要改权限来假装关掉。

「常驻」本身不是关闭理由。会用的常驻面留下。用户要自己选关哪些时，先按占法列出本轮查到的选项，等点名再改。

## 留什么

读写、命令、委派、联网这类核心面保持可用。

会用到的面留下，不论占法。调用才进的留下。关了也不省的留下。
