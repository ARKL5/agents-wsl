# Codex

## 配置位置

- `~/.codex/config.toml`：权限、沙箱、功能、模型、委派及插件设置。
- `~/.codex/agents/`：自定义 agent 定义。

## 个人约定

| 项目 | 约定 |
| --- | --- |
| 权限 | 全部开放，关闭沙箱 |
| 委派 | 保持启用 |
| 生图 | 关闭，同时移除相关系统 skill 入口 |
| 插件 | 不安装，也不配置市场 |
| 系统 skills | 只保留 `openai-docs` |

## 维护边界

改变生图状态时，功能开关和系统 skill 入口必须一起核对并同步处理。

## 验证方式

按任务查当前 `codex --help`、功能列表、插件和市场列表；官方字段、权限模式及自定义 agent 契约通过 `find-docs` 核查。验证配置解析和实际启用状态；上下文精简还需验证工具或 skill 入口已移除。

生视频、LSP、代码索引是否可配置，内置 agent 能否分别关闭，均按当前版本核查。
