**降秩**：把一个领域里的现象砍到不可再少的 **生成器**。拿这几根能把现象一个个生回来，才叫找到了 **秩**。

先分清两个方向：

- **天花板** 是 **基本假设**——不许问为什么、靠信才立。动摇一条，整套就塌。
- **地板** 是 **root rank**——一层层往下追，追到追不动。

天花板没看清，容易把信仰当真理说出去。先把它写在明处，再往下挖。

## 挖

每一步跟用户对齐后再走下一步。他砍的、补的、改名的，以他的为准。

1. **基本假设。** 问两句：这里什么是不许问的？什么是靠相信才成立的？写成几条，不展开论证。完成：用户认这几条是天花板。
2. **铺现象。** 列出十个以上有代表性的现象，只铺不解释。完成：用户认这份清单够当检验靶。
3. **递归下沉。** 先找现象底下紧挨着的那一层生成器。找齐了，站上去，再问这层底下还有没有更基本的。从现象一铲子猜到底，猜出来的底是悬空的。完成：站上某一层，再问不出更基本的——那层就是地板。
4. **合并同源。** 去掉一个，另一个还会自己冒出来，就合掉。
5. **砍。** 拿掉一根，剩下的还能反生成全部现象，就扔。
6. **反生成。** 剩下的几根把现象清单逐条复现。复现不了的，指向少了一根，回到下沉。
7. **解释力** 和 **难以变更。** 这几根能否推出清单外、现实里真有的现象（解释力）。随便改一根的一个细节，预测是否崩（难以变更）。还对，这根是松的 **伪根**，逼到只能这么说为止。

## 秩立住

五条都过，秩才立住：

- **生成性**：每条现象都能从这几根推回来
- **最小性**：拿掉任何一根，就有现象推不出来
- **独立性**：每两根之间找得到「一个动了另一个没动」的案例
- **解释力**：能推出清单外且验得上的现象
- **难以变更**：动一处细节，预测就错

过不了，回到下沉。用户说停就停。

## 取景框

地板找到了，再给这几根之间的关系起一个 **取景框**。先排除，再落下。默认想到钻井三层或 2x2，多半是懒。

| 关系 | 取景框 |
|---|---|
| 正交、可滑动 | 坐标系 |
| 一层托一层，最深是元命题 | 钻井 |
| 两端拉，案例落中间 | 光谱 |
| 互相正负推 | 环 |
| 一段接一段 | 链 |
| 一根分多根 | 树 |
| 多对多、无层级 | 网 |
| 涨落交替 | 振荡 |
| 超过两轴 | 切片 |

有一根线能展开成独立可调的状态参数，再叠一台坐标系当操作仪；不能滑就不要硬叠。取景框有名字就算完成。用户要看图再画。
